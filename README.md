# EMP Exclusive

News house for EMP Exclusive — Francistown, Botswana.

Music · Fashion · Media · House. Founded 19 December 2024.

This is the official page: feed, family, house notes, stills, stories.

## Run

```bash
npm install
npm run dev
```

## Launch

Connect the repo to Vercel (Hobby is free). Set `DATABASE_URL` to a Postgres database (Neon free tier works) so the feed, comments, and subscribe stay live.

Built with Grok.
